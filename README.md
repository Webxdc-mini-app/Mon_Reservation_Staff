# 門 スタッフ共有予約台帳

電話・個別チャット・店頭で受けた予約を、Delta Chat のスタッフ専用グループで共有する webxdc アプリです。

- バージョン：1.3.2（共有確認版）
- 配布ファイル：`Mon_Reservation_Staff_1.3.2.xdc`
- 利用環境：webxdc の共有機能に対応する Delta Chat

## はじめに

1. スタッフ専用グループに `.xdc` ファイルを一度送信します。
2. 全スタッフが、**同じメッセージに添付された台帳**を開きます。
3. 「共有履歴を反映済み」と表示されるまで待ちます。
4. 初回は「端末間の通信テスト」で、別の端末にも更新が届くことを確認します。

別のメッセージとして送った台帳を各自が開かないようにしてください。通常のブラウザでは共有機能を利用できず、予約登録もできません。

## 主な機能

- 予約の登録・編集、状態の変更（確認待ち／確定／取消）
- 来店日・状態による絞り込みと文字検索
- 来店日時順の一覧表示、50件ごとのページ切り替え
- 絞り込みに一致する件数・人数と、台帳全体の件数の表示
- 受付スタッフ・受付日時・最終更新スタッフ・更新日時の記録
- テスト番号による端末間の通信確認、診断情報の表示

## 予約を登録する

1. 「＋ 予約を登録」を押します。
2. 予約内容を入力します。
3. 「登録して共有」を押します。
4. 「共有履歴に反映しました」と表示され、一覧に登録されたことを確認します。

| 項目 | 入力内容 |
| --- | --- |
| お客様名 | 必須、80文字まで |
| 連絡先 | 電話番号や個別チャットの相手など、120文字まで |
| 来店日・来店時刻 | 必須 |
| 人数 | 必須、1〜999名 |
| コース | 席のみ・おまかせなど、80文字まで |
| 受付経路 | 電話／個別チャット／店頭／その他 |
| 予約状態 | 確認待ち／確定／取消 |
| 引継ぎメモ | アレルギー・席の希望・折り返し事項など、2,000文字まで |

新規登録時の初期値は、端末の今日の日付・19:00・2名・確認待ち・電話です。実際の予約内容に合わせて変更してください。

## 予約を変更・取消する

- 内容を変える場合は、対象予約の「編集」を押して修正し、「変更して共有」を押します。
- 確定する場合は「確定する」、取り消す場合は「取消にする」を押します。
- 取消済みの予約も残ります。状態を「取消」または「すべて」にすると確認できます。
- 取消済みの予約は「確定する」で確定に戻せます。確認待ちに戻す場合は編集画面で状態を変更します。

編集中に対象予約の更新を受信した場合は、保存を停止します。入力内容を控えて「閉じる」を押し、一覧から最新内容を開き直してください。

## 一覧・検索

- 「今日」で当日の予約、「全日程」で日付の絞り込みを解除します。
- 「有効な予約」は確認待ち・確定を表示し、取消を除外します。
- 検索対象は、氏名・連絡先・メモ・受付スタッフ・最終更新スタッフ・コース・受付経路です。
- 一覧は来店日時の昇順です。51件以上ある場合は「前の50件」「次の50件」で切り替えます。
- 表示人数の合計には、取消済み予約の人数を含めません。

## 共有について

予約の更新は webxdc の共有履歴を通じて反映されます。他端末への反映には Delta Chat の通信が必要です。

**「共有履歴を反映済み」や「共有履歴に反映しました」は、他端末への配達確認ではありません。** 必要に応じて、相手側の一覧や通信テストで確認してください。

同じ予約への更新は、受信した更新順で反映されます。同時編集を完全に防ぐ仕組みではないため、同じ予約を複数人で同時に変更することは避けてください。

送信間隔の制御により、保存後に待ち時間が発生することがあります。共有履歴への反映待ちの間は、予約の登録・変更などの操作が制限されます。

## 端末間の通信テスト

1. 両端末で同じ台帳を開き、「端末間の通信テスト」欄を表示します。
2. 片方で「テスト番号を送る」を押します。
3. もう片方の「受信したテスト番号」に同じ8文字の番号が表示されることを確認します。

テストでは予約は作成されません。送信側で「この端末の履歴に戻りました」と表示されても、相手側での受信確認は別途必要です。受信番号は直近10件まで表示します。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| 共有機能を利用できない | Delta Chat のスタッフ専用グループ内にある、全員と同じ台帳メッセージから開いてください。 |
| 共有履歴の読み込みに失敗する | 台帳を閉じて開き直してください。履歴を読み込めるまで登録できません。 |
| 送信に失敗する | 入力内容と通信状態を確認し、表示された案内に従って再保存してください。 |
| 共有履歴への反映を確認できない | 入力内容を控え、台帳を開き直して登録状況を確認してください。再登録前に、重複していないか確認してください。 |
| 他端末に更新が表示されない | 同じメッセージの台帳を開いているか、グループへの送信可否や通信状態を確認し、通信テストを行ってください。 |
| 他のスタッフの更新で保存が止まる | 入力内容を控えて編集画面を閉じ、最新の予約内容を開き直してください。 |

「詳しい診断情報」を開くと、バージョン・送受信の状態・受信数・エラーなどをコピーできます。通常の診断項目に予約の氏名・連絡先・メモは含まれませんが、エラー文や実行環境も含むため、共有前に内容を確認してください。

## 運用上の注意・制限

- 氏名・連絡先・メモはグループの参加者全員に共有されます。スタッフ専用グループで利用してください。
- 満席や予約時間の重複は自動判定しません。空席を確認してから確定してください。
- お客様への自動通知はありません。電話・個別チャットでの連絡は担当者が行ってください。
- この版には、予約の完全削除、CSV入出力、専用のバックアップ・復元画面は実装されていません。
- 日付の「今日」や記録日時の表示は端末の日時設定に依存します。

## ファイル構成

`.xdc` は ZIP 形式のアプリパッケージです。

| ファイル | 役割 |
| --- | --- |
| `manifest.toml` | アプリ名・バージョン・アイコンの定義 |
| `index.html` | 予約フォーム・一覧・通信テストなどの画面 |
| `style.css` | 画面のスタイル |
| `app.js` | 画面操作、検索、共有更新の送受信、診断処理 |
| `ledger.js` | 予約データの検証と共有更新の適用 |
| `transport.js` | 送信キューと送信間隔の制御 |
| `icon.png` | アプリアイコン |
